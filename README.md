# SWINGLAB

野球のスイング動画をブラウザで分析するアプリです。

- コマ送り・フェーズ計測・角度計測・バット軌道の追跡
- 1本の動画から複数スイングを検出して、ベストを切り出して保存
- 成長の推移グラフ
- 共有ファイル(.swinglab)で記録を受け渡し

## 記録の保存先

保存した動画と記録は、このリポジトリの `data/` フォルダに入ります(`data/index.json` が記録、`data/videos/` が動画)。
URL を知っている人は誰でも閲覧でき、保存・編集・削除は「編集モード」にアクセストークンを入れた人だけができます。
リポジトリは公開なので、`data/` の中身は GitHub 上でも見られます。削除した動画も変更履歴には残ります。
